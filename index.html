05

Coming soon: two new builds

My next two projects bring industrial automation down to desk size. Each one has a budget of $50 and gets a full case study when it's done.

Build 01 · Planned

Teach-and-Repeat Robot Arm

A 4-axis desktop robot arm controlled by an Arduino. I'll move it by hand with joysticks, save each position, and have it play the whole pick-and-place routine back on its own. That's how industrial robot arms on assembly lines are taught.

  • Show: servo control, saving positions to memory, smooth motion between points
  • Parts: 4-DOF arm kit with servos, joystick modules, external 5–6 V power
  • Stretch goal: type commands over serial or let a sensor trigger the routine
  1. Plan
  2. Order parts
  3. Build
  4. Code
  5. Case study
Build 02 · Planned

Color-Sorting Mini Conveyor

A small conveyor that carries blocks past a color sensor. A servo gate pushes each block into the right bin, and a break-beam sensor counts them. It's the same sense, decide, act loop as a factory sorting line, written like PLC logic.

  • Show: sensor calibration, motor control, timing between sensor and gate, counting
  • Parts: geared DC motor, color sensor, servo, IR break-beam, laser-cut frame
  • Stretch goal: an LCD showing totals for each color, with start and stop buttons like the demo above
  1. Plan
  2. Order parts
  3. Build
