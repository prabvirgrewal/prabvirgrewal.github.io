A hotel booking system in C++

A console application that manages bookings for a 12-room hotel. It checks every night of a stay for conflicts, prices the booking, and saves everything to a file so nothing is lost when the program closes.

The problem

Our team of three had to apply object-oriented programming to a real-world system. We chose a small hotel: rooms with different types and prices, guests, and reservations that must never double-book a room.

Features

  • Show all 12 rooms across 5 types: Standard ($120), Deluxe ($160), Suite ($220), Family ($250) and Executive ($300) per night
  • Book a stay of 1 to 14 nights, with checks for invalid dates, past dates and leap years
  • Show day-by-day availability for the whole stay, then pick a specific room or browse by room type
  • Give each booking a unique random 4-digit booking ID and calculate the total price
  • Cancel by booking ID, with a confirmation step
  • Save every booking to a file and load it on the next run

Class design

ClassResponsibility
RoomRoom number, type and price per night
CustomerGuest name and contact number
DateDay, month and year for check-in and check-out
ReservationLinks a customer to a room and dates, with an ID and total price
ReservationManagerRuns the menu, checks availability, books, cancels, and saves and loads data

Each class has one job and keeps its data private behind getters. That kept the program easy to test, and new room types or prices can be added without touching the booking logic.

The hard part: dates

A room isn't simply "booked" or "free": it can be taken one week and open the next. The system checks whether a requested stay overlaps any existing reservation for that room:

// Two stays overlap if each one starts before the other ends
bool ReservationManager::datesOverlap(Date aIn, Date aOut, Date bIn, Date bOut) {
    return dateToTime(aIn) < dateToTime(bOut) && dateToTime(bIn) < dateToTime(aOut);
}

bool ReservationManager::isRoomAvailableForDates(int roomNumber, Date in, Date out) {
    for (Reservation r : reservations)
        if (r.getRoomNumber() == roomNumber &&
            datesOverlap(in, out, r.getCheckIn(), r.getCheckOut()))
            return false;
    return true;
}

Dates are converted to time_t with mktime, so counting nights is just a subtraction divided by the seconds in a day. A separate check handles leap years and the number of days in each month.

What I learned

  • How to split a real system into classes with clear responsibilities
  • That edge cases (leap years, overlapping stays, past dates) take more work than the main feature
  • How to save and reload structured data with file streams
  • How to divide a program between three people and still keep it consistent
